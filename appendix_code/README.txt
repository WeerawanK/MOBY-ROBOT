ชุดไฟล์สำหรับภาคผนวก

โฟลเดอร์ esp32: โค้ดควบคุม ESP32 และไฟล์ทดสอบจอย
โฟลเดอร์ raspberry_pi: โค้ด Flask กล้อง การบันทึกภาพ และ Google Drive/Sheets
โฟลเดอร์ docs: คู่มือการติดตั้งและการใช้งาน

ไฟล์สำคัญ:
- esp32/esp32_s3_servo_test.ino คือโค้ด ESP32 ที่ใช้งานหลัก
- raspberry_pi/app_realtime.py คือโค้ด Flask รุ่นปรับปรุงการสตรีมภาพ

โฟลเดอร์นี้ตั้งใจไม่รวมข้อมูลลับ เช่น .env, Google client secret และ token.json
